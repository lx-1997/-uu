# RDKClaw 成长与 OpenClaw 养成计划（2026-03-26）

## 目标

把系统从“会执行”升级为“会学习、会沉淀、会教会板端”。

## 一、RDKClaw 如何持续变聪明

### 1) 经验闭环（每次任务都沉淀）

- 输入：用户目标、设备环境、执行日志、结果质量
- 处理：自动提炼为“问题模板 + 解决步骤 + 风险 + 回滚策略”
- 输出：写入知识库（可检索、可复用、可评分）

建议事件：

- `solution_captured`
- `solution_validated`
- `solution_regressed`

### 2) 检索增强（先查再答）

- 每次规划前先查：官方文档 > 已验证经验 > 社区经验
- 结果带置信度与来源分层，低置信度必须触发验证步骤

### 3) 质量反馈（好方案会升权）

- 成功率、耗时、重试次数、用户确认作为评分
- 高分方案自动晋升为“推荐模板”
- 连续失败方案自动降级或进入“待复审”

### 4) 反思机制（任务后复盘）

- 每次 run 结束，生成 3 条“下次更优动作”
- 复盘条目写入长期记忆，进入下一次提示上下文

## 二、RDKClaw 如何“养”板端 OpenClaw

### 1) 教学单元（可安装技能包）

- 把一次成功任务转成教学包：
  - 触发条件
  - 环境前置
  - 标准流程
  - 异常回退
  - 验证命令

### 2) 教学回放（教完必须考）

- 安装后自动回放 1 次标准任务
- 验证通过才标记“已学会”
- 失败则自动回滚并回传失败证据

### 3) 板端能力地图（可见成长）

- 按设备展示：
  - 已掌握技能
  - 最近成功率
  - 漂移告警（版本变更后失效）

### 4) 协同策略升级

- `board_primary`：板端优先，PC 只兜底
- `collaborative`：PC 先规划，板端执行
- `local_only`：仅 PC 执行（高风险/高复杂）

按任务类型和历史成功率自动切换。

## 三、建议里程碑

### P0（1-2 周）

- 教学包数据结构 + 审批入口
- 安装/回放/验证闭环
- 教学日志可视化

### P1（2-4 周）

- 自动升权与降权
- 失败原因聚类
- 按设备能力看板

### P2（4-8 周）

- 多渠道（Studio/飞书/微信）统一教学状态
- 云端知识同步与团队共享

## 四、验收指标

- 首次解决率（FTR）提升
- 同类问题平均处理时长下降
- OpenClaw 独立完成率上升
- 需要 RDKClaw 兜底次数下降
- 用户“确认已解决”比例提升
