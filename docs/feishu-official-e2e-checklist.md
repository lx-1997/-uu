# RDKClaw 飞书官方模式联调清单

## 1. 基础配置

- 在 `设置 -> 飞书` 填写 `App ID`、`App Secret`。
- 连接模式选择 `websocket (official)`。
- 私信策略保持 `pairing（默认）`。
- 点击“保存飞书配置”后，点击“重启”通道。

## 2. 飞书开放平台配置

- 应用能力中开启机器人。
- 事件订阅启用 `im.message.receive_v1`。
- 发布应用版本并完成可见范围配置。

## 3. 配对审批链路

- 新用户私信机器人发送任意文本。
- 机器人应返回 6 位配对码。
- 回到 RDK Studio `设置 -> 飞书 -> 配对审批`，应出现对应请求。
- 点击“批准”后，绑定列表应新增该账号。

## 4. 消息执行链路

- 已批准账号再次私信机器人发送问题。
- 机器人应返回 RDKClaw 执行结果（长文本按分片发送）。
- `运行状态` 中最近事件时间应更新。

## 5. 兼容模式回退验证

- 将连接模式切换为 `webhook (compat)` 并保存。
- Webhook 地址使用 `/api/channels/feishu/webhook`。
- 发起 challenge 校验与消息回调应可正常工作。

## 6. 重启恢复验证

- 重启 RDK Studio 服务后重新进入设置页。
- 已绑定账号和待审批请求应从本地持久化恢复。
- 若为 websocket 模式且已启用，应可自动恢复通道运行。
