# RDK Studio 用户使用手册

## 前言：软件特色

RDK Studio 是面向 RDK 开发者套件的一体化开发工作台，目标是让「连接设备、部署能力、调试问题、持续开发」都在一个界面里完成。

核心特色如下：

- 一站式：把设备连接、终端、文件、远程桌面、IDE、OpenClaw、技能管理、系统烧录统一到同一入口。
- AI 驱动：通过底部 AI 对话区把高频操作转成自然语言任务，减少重复命令输入。
- 面向实战：既支持首次上板的引导流程，也支持日常开发中的远程操作、日志排查和快速修复。
- 双路径协同：既可以手工操作每个页面，也可以让 AI 协助跨页面执行任务。

## 页面功能说明（逐页）

### 1) 工作台（Dashboard）

工作台是默认首页，用于总览设备状态和快速进入关键功能。

- 显示当前设备在线状态、RDKClaw 状态、OpenClaw 状态。
- 显示设备关键指标（如 CPU、内存、温度、磁盘、运行时长）。
- 提供快捷入口（如进入终端、OpenClaw、设备体检、快捷开发）。
- 在未连接设备时，提供添加设备和重新引导入口。

适用场景：首次确认环境是否可用、每天开始开发前做健康检查。

### 2) OpenClaw

OpenClaw 页面用于管理板端 Agent 网关及相关配置。

- 一键部署 OpenClaw（含部署日志与进度状态）。
- 查看网关运行状态、版本、是否就绪。
- 配置模型网关参数（模型提供商、模型 ID、API 配置）。
- 管理 OpenClaw 对话与执行状态。

适用场景：让设备具备板端智能能力，并持续维护其可用性。

### 3) 技能工坊（Skills）

技能工坊用于查看、创建、编辑和部署技能。

- 查看套件端已安装技能。
- 在线编辑技能的 `SKILL.md` 并保存回设备。
- 新建技能并部署到套件端目录。
- 从 Skill 中心或 SkillHub 预览并批量部署技能。
- 支持“链接转技能”，把外部链接内容转为可执行技能草稿。

适用场景：沉淀团队常用流程、封装重复任务。

### 4) 终端（Terminal）

终端页面提供远程命令行能力，支持 SSH 会话与 USB 串口调试场景。

- 建立/切换多终端会话。
- 连接设备后执行命令、查看日志、排查服务。
- 支持 USB 串口调试口连接（适合网络未就绪时）。

适用场景：安装依赖、查看系统日志、服务诊断、网络排障。

### 5) 文件（Files）

文件页面用于设备文件管理和在线编辑。

- 浏览设备目录、切换路径、搜索文件。
- 上传和下载文件（支持目录打包下载）。
- 在线编辑文本文件并保存回设备。
- 支持拖拽上传和常用路径快速跳转。

适用场景：上传模型/脚本、修改配置、导出日志。

### 6) 远程桌面（VNC）

远程桌面页面用于连接开发板图形桌面。

- 一键检查/启动 VNC 服务并连接可视化桌面。
- 支持画质切换、缩放策略切换、全屏与浮窗模式。
- 提供连接日志与错误提示，便于定位失败原因。

适用场景：图形界面应用调试、可视化验证、演示操作。

### 7) IDE

IDE 页面用于访问设备端 code-server，进行在线代码开发。

- 一键连接设备端 code-server。
- 未安装时可触发安装流程并自动重试连接。
- 支持刷新、全屏、浮窗等编辑体验增强。

适用场景：在设备代码上直接迭代、快速改脚本和配置。

### 8) 烧录（Flasher）

烧录页面用于制作系统镜像介质并完成写盘流程。

- 按向导选择板型、镜像和目标盘。
- 执行写盘、校验并展示阶段进度。
- 提供错误去重与过程日志，便于定位烧录失败原因。

适用场景：新板初始化、系统重装、版本切换。

### 9) 地瓜生态（论坛 / RoboGo 内嵌）

通过左侧底部入口可打开地瓜开发者论坛和 RoboGo 云平台（认证后内嵌展示）。

- 快速进入论坛进行问题交流与资料查询。
- 快速进入 RoboGo 云端能力页面。

适用场景：查资料、协作交流、衔接云端业务。

## 全局功能补充

以下不是独立页面，但会在全流程中高频使用：

- 设备面板：选择设备、切换设备、删除设备、添加设备。
- 设置面板：AI 引擎、人格行为、飞书/微信通道、设备连接等配置。
- AI 对话区（AIDock）：自然语言发起任务、查看过程回显、提交附件、继续执行任务。
- 顶部工具栏：快速查看设备状态、WiFi 状态、IP 信息、账号入口。

## 上手路径（建议按顺序）

### 路径 A：首次上手（推荐）

1. 打开 RDK Studio，进入工作台。
2. 添加设备（建议先走 SSH 网络连接；X5 可按需使用 Type-C 闪连）。
3. 在工作台确认三件事：设备在线、网络可达、基础指标正常。
4. 打开 OpenClaw，完成模型配置并执行一键部署。
5. 用终端执行基础命令验证系统可用。
6. 用文件页面上传一个测试脚本并执行。
7. 打开 IDE 或 VNC，确认图形/开发链路可用。
8. 进入技能工坊，部署一个基础技能作为能力验证。

### 路径 B：日常开发

1. 进工作台看状态（在线、温度、资源占用）。
2. 通过 AI 对话区下达任务，必要时切到终端执行精细命令。
3. 在文件页上传/下载素材，在 IDE 修改代码。
4. 需要可视化时切到 VNC 观察实际运行效果。
5. 结束前回到工作台做一次健康检查。

### 路径 C：故障排查

1. 工作台先看设备是否在线、是否联网。
2. 终端查看日志和服务状态。
3. OpenClaw 查看网关状态与部署日志。
4. VNC/IDE 若失败，先排查对应服务是否启动、端口是否就绪。
5. 必要时回到烧录页面重做系统介质并重新验收。

## 最小可用清单（验收建议）

完成首次接入后，至少确认以下项目全部通过：

1. 能添加并保存设备，且设备在线状态正常。
2. 终端可连接并执行命令。
3. 文件可上传、下载、编辑并保存。
4. IDE 或 VNC 至少有一个可稳定连接。
5. OpenClaw 能部署成功并显示可用状态。
6. AI 对话区可正常收发消息并触发任务。
